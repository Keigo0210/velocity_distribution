# ChatGPT共有用コンテキスト

## 依頼例

添付した進捗報告と図をもとに、研究・開発の進捗報告資料を作成してください。対象読者はCFDの基礎知識を持つ技術者です。事実、推定、未確認事項を分け、Re=100で誤差域が拡大した理由を力学的観点と数値計算的観点から説明してください。

## 解析の概要

- FEM solverとSTAR-CCM+の速度分布比較。
- 対象断面: center=(10,0,15) mm、normal=(1,0,-1)。
- 比較時刻: index 300、37.5 s。
- Re=10は入口速度1 mm/s、Re=100は10 mm/s。
- 両ケースともrhoとmuは同じで、dt=0.125 s。

## 重要な処理変更

- 旧方式: 共通点から異なる3Dメッシュへ直接sample。セル境界・点配置差が人工的な不連続として現れた。
- 新方式: 両メッシュを同一平面でsliceし、断面座標(s,t)へ変換後、同じ501 x 401格子へ三角形線形補間して比較。
- STARのセル速度は点データへ変換してからslice。
- 主指標: `abs(speed_FEM-speed_STAR) / max(speed_STAR, 0.05*U95)`。
- 補助指標: `abs(speed_FEM-speed_STAR) / U95`。

## 解釈

- Re=100では局所誤差だけでなくU95正規化誤差も増加しており、分母が小さいことだけでは説明できない。
- Re=10ではFEM/STARの分岐流量配分がほぼ一致するが、Re=100では側枝割合がFEM 29.5%、STAR 34.3%へ分かれる。
- 高Reでは慣性、直進性、分岐局所損失、出口圧力条件への感度が増す。
- 同じメッシュ・dtを使用しているため、Re=100では境界層解像度と移流CFLの条件が相対的に厳しい。
- index 280/290/300で結果はほぼ一定で、未収束や瞬時位相差は主因ではない。

## 注意点

- 分岐流量割合は共通格子上の断面平均法線速度から算出した近似値。最終確認では各ソルバーの面積積分流量を直接出力するべき。
- STARのセル→点変換がプリズム層の急勾配をぼかす可能性がある。
- STARとFEMの出口境界条件が完全に等価かは未確認。
